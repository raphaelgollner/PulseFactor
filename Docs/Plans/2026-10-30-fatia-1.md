# Fatia 1 — Voo, Estação, Mineração e Piratas — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Uma cena jogável onde o jogador pilota uma nave em blocos (estilo Everspace), alterna cockpit/terceira pessoa, usa subluz/cruzeiro/dobra num sistema solar em escala grande, pede docagem numa estação com pouso automático, compra/vende no terminal, minera asteroides e vê piratas procedurais patrulhando.

**Architecture:** Regras de jogo em classes C# puras (sem MonoBehaviour) testadas em EditMode; MonoBehaviours finos fazem a ponte com física, input e UI. Dados em ScriptableObjects. Posições do mundo em `double` com origem flutuante; corpos distantes viram "proxies" escalados. Arte provisória: prefabs primitivos gerados por script de editor.

**Tech Stack:** Unity 6000.3.9f1, C#, URP 17.3.0, Input System 1.12.0, Unity Localization 1.5.8, Unity.Mathematics, Unity Test Framework 1.6.0 (NUnit), uGUI.

**Spec:** `Docs/Design/2026-10-30-pulsefactor-design.md` (ver especialmente §3, §4, §5, §7, §8 e §9.1 — a primeira fatia).

## Global Constraints

- Unity **6000.3.9f1**. Não atualizar o editor.
- Todo código em `Assets/_Project/`, namespace raiz `PulseFactor`. Nomes de código em inglês; textos de jogo via Localization (PT-BR e EN).
- Nenhum texto de UI hardcoded: sempre `LocalizedString` da tabela `UI`.
- Valores de balanceamento vivem em ScriptableObjects, nunca em constantes espalhadas.
- Modo de teste (§9.1): comprar não desconta créditos; vender credita; reputação fixa em 0.
- Classes: Scout carga 50 / 1 arma / casco Padrão 100 HP; Cargo 500 / 2 / Padrão 100; Assault 10 / 3 / Militar 200. 1 slot de skill cada.
- Aceleração: Scout > Assault > Cargo. Carga reduz só a velocidade máxima, nunca a aceleração.
- Peças multiclasse (Cruise, Type C, Horder) montam em qualquer classe; exclusivas (Rapid Fire, Type A, Crusader) só na própria classe. O **corpo** define a classe.
- Piratas: sempre corpo de Assault; pintura com vermelho/preto/branco (uma cor ou mescladas); surgem só longe de estações, em grupos de 1–5.
- Sem armas nos modelos dos blocos; blocos expõem `WeaponMount` vazios.
- Os testes rodam com o editor **fechado**:
  `"C:\Program Files\Unity\Hub\Editor\6000.3.9f1\Editor\Unity.exe" -batchmode -projectPath E:\UNITY_PROJECTS\PulseFactor -runTests -testPlatform EditMode -testResults Logs\editmode.xml -logFile Logs\editmode.log`
  (troque para `PlayMode`/`playmode.xml` nos testes de PlayMode). Exit code 0 = passou, 2 = falhas; detalhes no XML.

### Teclas (Input Actions, remapeáveis)

Mouse = mira; W/S acelerar/desacelerar; A/D strafe; Espaço/C vertical; Q/E roll; LMB/RMB fogo primário/secundário; 1/2/3 skills; **X** cruzeiro; **J** dobra; **L** pedir docagem; **V** alternar câmera; **F** terminal/decolar; **T** selecionar alvo (mais próximo à mira). Gamepad: analógico direito mira, esquerdo strafe/vertical, RT/LT fogo, bumpers roll, D-pad skills, A dobra, B cruzeiro, Y câmera, X interagir, View docagem.

## Review Focus

1. **Precisão a grandes distâncias**: após voar/dobrar 10⁹ m, a nave não pode tremer nem os corpos "pularem" no rebase. → teste em Task 7.
2. **Dobra com alvo atrás de uma massa ou alvo nulo**: J sem alvo, ou com mass lock, não pode entrar em dobra nem travar o estado. → teste em Task 8.
3. **Carga cheia/negativa**: comprar ou minerar além da capacidade não pode estourar a carga; vender mais do que tem não pode ficar negativo. → testes em Tasks 3 e 10.
4. **Docagem com todas as docas ocupadas ou saindo do alcance**: pedido negado com mensagem; sair de 7,5 km cancela a autorização. → teste em Task 9.
5. **Gerador pirata sem peças válidas**: se faltar alguma peça compatível, o gerador deve falhar com erro claro, nunca montar nave sem corpo Assault. → teste em Task 12.
