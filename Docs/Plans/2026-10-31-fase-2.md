# Fase 2 — Contratos, Reputação, Save e Novas Estações — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Contratos de entrega e requisição com prazo em tempo de jogo, reputação por corporação com desconto, economia real (sem modo de teste), save automático, plataformas estilo Elite, Posto Avançado Apollo e Estação Magna.

**Architecture:** Regras em C# puro (Contract, ContractGenerator, ContractLog, Reputation, GameClock, SaveData) testadas em EditMode; MonoBehaviours/terminal/HUD consomem. Construtores de estação por estilo (Ring, Outpost, Industrial) compartilham um PadBuilder.

**Tech Stack:** igual à fatia 1 (Unity 6000.3.9f1, URP, UI Toolkit, Localization, Test Framework).

**Spec:** `Docs/Design/2026-10-30-pulsefactor-design.md` §12 (e `Docs/Lore.md`).

## Global Constraints
- Fluxo de trabalho: o autor aplica no Unity (Ctrl+R, menus, Test Runner); resultados em `Logs/TestResults-*.txt`, erros de compilação no Editor.log.
- Textos sempre via tabela `UI` (PT-BR/EN). Nomes: Estação Gollner / Gollner Station; Posto Avançado Apollo / Apollo Outpost; Estação Magna / Magna Station; Nova Technology; Magna Hauling Co.; Atlas Universal; Federação / Federation; setor **Centaurus**.
- Tempo de contrato em **tempo de jogo**. Entrega: 30 min + 25 min/salto. Requisição: 2 h. Máx. 5 ativos. Mural 3–6 ofertas, renova a cada 20 min.
- Reputação −100..100; descontos de compra 2/5/8/12% em ≥10/25/50/80.
- `GameConfig.testMode = false`.

## Review Focus
1. Carga reservada de contrato não pode ser vendida no mercado nem perdida ao vender outro recurso. → Task 2/3.
2. Prazo vencendo com a nave docada ou em dobra: falha uma vez só, sem cobrança dupla. → Task 3.
3. Multa maior que o saldo: nunca deixa créditos negativos. → Task 3.
4. Save corrompido/ausente/versão antiga: o jogo inicia novo, sem travar. → Task 4.
5. Contrato com destino em estação inexistente (dados mudaram): ignorado com log, sem exceção. → Task 3/4.

**Interfaces:**

- `[Serializable] Contract { string id; ContractType type; string issuerStationId, issuerCorpId, destinationStationId; string resourceId; int quantity, delivered; long reward, fine; double deadline /* segundos de jogo, absoluto */; double duration; int repGain, repLoss; ContractState state; }`

- `ContractLog { const int MaxActive = 5; IReadOnlyList<Contract> Active; AcceptResult Accept(Contract, CargoHold, Func<string,ResourceDef>, double now); DeliveryResult Deliver(string stationId, CargoHold, Wallet, Reputation, Func<string,ResourceDef>); List<Contract> Tick(double now, CargoHold, Wallet, Reputation, Func<string,ResourceDef>) /* retorna os que falharam */; void Abandon(string id, ...) }`

- [ ] Testes gerador: 3–6 ofertas; entrega Gollner→Apollo dura 1800 s; com 1 salto 3300 s; requisição 7200 s; entrega só com recurso vendido pela emissora; requisição só com recurso comprado; destino nunca é a própria emissora; mesma seed = mesmas ofertas.
- [ ] Testes log: aceitar entrega carrega e reserva; sem espaço → recusa; 6º contrato → recusa; entregar no destino paga recompensa, remove carga, rep +; entregar em estação errada não faz nada; requisição parcial acumula e só paga ao completar; prazo vence → falha uma vez (Tick repetido não cobra de novo), carga reservada confiscada, multa limitada ao saldo (nunca negativo), rep −; abandonar = falha; destino inexistente → ignora sem exceção.
